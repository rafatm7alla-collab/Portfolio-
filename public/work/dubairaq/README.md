# dubairaq — images

Drop files straight into this folder. Extension and capitalisation do not
matter: hero.jpg, COVER.JPG, Hero.png and 01.jpeg all resolve.

    hero    the cover — used on the homepage, the /work panels and the
            case-study hero. Also accepts: cover, main, 00
    01      full-bleed image
    02      left image of the offset pair (portrait crop suits it)
    03      right image of the pair (smaller, landscape)
    04      full-bleed image

Any slot left empty renders a proportioned grey block, never a broken
image. Run `npm run images` from the project root to see what is missing.

Largest available resolution please — at least 2400px on the long edge.
